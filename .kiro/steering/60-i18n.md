# i18n

- Lingue obbligatorie: `it`, `en`, `fr`, `es`
- Chiavi: `domain.scope.key` (es. `app.title`, `world.character.status.active`)
- Fallback: inglese se traduzione mancante
- File JSON in `locales/{lang}/common.json` — mantenere tutte le lingue allineate
- Termini di dominio IT: usare glossario `docs/glossary.md` (PG, PNG, Luogo, …)
- Non tradurre identifier di codice nei file JSON
